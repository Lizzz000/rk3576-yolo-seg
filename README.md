# rk3576-yolo-seg

面向 **嘉立创泰山派 RK3576 开发板（Linux ARM64）** 的 C++17 **YOLOv8-seg 板端推理与后处理示例**，支持图片与摄像头识别。

> 本项目经过 AI 辅助修改，仍可能存在错误或兼容性问题。使用前请检查代码，并在自己的硬件和模型上验证结果。

## 项目说明

本项目从机器人视觉工程中提取识别部分，覆盖从图像输入到检测框与掩膜几何结果输出的板端处理链路，适合模型验证和 C++ 视觉程序集成。

处理流程：**图片 / 摄像头输入 → NV12 转换 → RGA 预处理 → RKNN / NPU 推理 → 框解码与 NMS → 掩膜投影及几何统计 → 结果输出**。

输出包含类别、检测框、分数，以及掩膜面积、中心和底点。当前不导出完整掩膜像素或彩色实例蒙版；项目范围为板端推理，不包含训练与模型转换。

模型和类别由使用者提供，输入尺寸从模型读取，兼容约定见 [模型说明](MODEL.md)。项目不附带模型、数据集或 SDK。图片和摄像头入口位于 `examples/`，推理接口与实现位于 `include/`、`src/`。

## 性能

[历史性能参考](PERFORMANCE.md)：嘉立创泰山派 RK3576 开发板，YOLOv8n-seg INT8、输入 1280×736、NPU `CORE_0_1`；1080P NV12 相机采集约 30 FPS，视觉处理观测约 **22.0–24.1 FPS**。这是原项目 2026-09-04 无稳定目标场景的数据，24.1 FPS 为最高观测值，**当前通用版尚未重新上板实测**。
